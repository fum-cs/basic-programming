A first-semester **B.Sc.** course (3 units, 48 hours) in the **Computer Science** curriculum at the
[Computer Science Dept., Ferdowsi University of Mashhad](https://fum-cs.github.io/). The official
syllabus is at
[fum-cs.github.io/docs/curriculum/base/Computer-Fundamentals-and-Programming](https://fum-cs.github.io/docs/curriculum/base/Computer-Fundamentals-and-Programming).

The course language is **C**. The emphasis — per the syllabus — is on **problem solving and
algorithmic thinking**: from a simple computational model of the computer, to algorithms, to a
high-level language that expresses them.

## Learning outcomes

By the end of the course students should be able to:

1. Describe the basic structure of a computer as a computational model and relate its components to program behaviour.
2. Design and express algorithms independently of any programming language (sum, average, search, …).
3. Translate algorithms into C: variables and constants, conditionals, all loop forms.
4. Decompose programs into functions with parameters; explain scope.
5. Use arrays and files; connect arrays, pointers, and strings.
6. Reason about running time and memory consumption of simple programs.
7. Write and analyse recursive algorithms.
8. Implement searching and sorting algorithms and compare them.

## Topics (following the official syllabus)

1. Computer structure as a computational model; hardware components and how they cooperate
2. Simple algorithms on that model: summing numbers, averages, searching
3. A high-level language (C): variables, constants, expressions
4. Conditional and control structures; loop forms
5. Methods (functions) and parameters
6. Arrays and files
7. Running time and memory usage
8. Recursive algorithms
9. Searching and sorting algorithms

Practice on online judges (e.g. [CodinGame](https://www.codingame.com)) and course exercises
complement the lectures; see the [TA workflow](/CONTRIBUTING.md) for how exercises are added.
